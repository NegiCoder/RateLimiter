How Token Bucket Works

Simple, interview-friendly explanation.

  1. Each client gets a bucket with a fixed capacity.
  2. Every allowed request consumes one token.
  3. Tokens refill over time at a configured rate.
  4. If no token is available, the API returns 429.
  5. Redis + Lua makes the check atomic under concurrency.
